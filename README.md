# Pomodoro


A ideia desse projeto de pomodoro é simplesmente ter um pomodoro que fica sempre fixo na system tray do seu SO, não tem compatibilidade com tudo, naturalmente, mas a maioria dos sistemas tem funcionado bem (exceto em alguns gerenciadores de janelas no linux, aqueles baseados em mosaicos)

Para rodar o projeto é simples, basta rodar os seguintes comandos

## Clone o Projeto
```bash
git clone https://github.com/athavus/pomodoro.git
cd pomodoro
```
## Instale as dependências e rode o projeto
```bash
npm install
npm start
```
